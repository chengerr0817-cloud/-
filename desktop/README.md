# 墨迹博客 · 桌面控制台

一个 Electron 桌面应用，把博客的本地服务管理可视化：**一键启停前后端、实时看日志、查看站点统计**，不用再开终端敲命令。

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| **服务状态** | 实时显示前后端运行状态、PID、端口、健康检查返回码，每 2.5 秒自动刷新 |
| **一键启停** | 单独启动/停止/重启某个服务，或顶部按钮一次性操作全部 |
| **端口冲突识别** | 端口被其他程序占用时明确提示，而不是静默失败 |
| **实时日志** | 深色终端风格面板，增量拉取（1.2 秒/次），错误行自动标红、警告标黄 |
| **站点统计** | 已发布文章、草稿、标签、累计阅读与字数，后端一启动就自动拉取 |
| **数据路径** | 显示数据库文件大小与图床文件数，一键在文件管理器中定位 |
| **快捷入口** | 直接跳转博客首页、写文章、文章管理、图床管理 |
| **托盘常驻** | 关闭窗口不退出，服务继续跑；点托盘图标可随时唤回 |

## 快速开始

```bash
cd desktop
pnpm install     # 首次会下载 Electron 二进制（约 100MB）

pnpm dev         # 开发模式：热更新
pnpm start       # 构建后直接运行
```

打包成安装包：

```bash
pnpm dist        # 产物在 release/ 目录
```

- macOS：`.dmg` + `.zip`
- Windows：`.exe`（NSIS 安装版 + 免安装版）
- Linux：`.AppImage` + `.deb`

## 它是怎么工作的

桌面应用**不重复实现服务管理逻辑**，而是直接复用仓库里已有的约定：

| 约定 | 位置 | 用途 |
| --- | --- | --- |
| PID 文件 | `.run/<service>.pid` | 判断服务是否由本工具启动 |
| 日志文件 | `logs/<service>.log` | 读取输出 |
| 启动命令 | `backend` 用 `tsx src/index.ts`，`frontend` 用 `vite` | 与 `scripts/start-local.sh` 一致 |

这意味着**桌面控制台和命令行脚本可以混用**——用脚本启动的服务，桌面端能识别；用桌面端启动的服务，脚本也能停。

### 架构

```
desktop/
├── src/
│   ├── main/                    # 主进程（Node 环境，有完整系统权限）
│   │   ├── index.ts             # 窗口、托盘、IPC 注册、单实例锁
│   │   └── service-manager.ts   # 服务启停 / 状态探测 / 日志读取 / 统计
│   ├── preload/
│   │   └── index.ts             # contextBridge 暴露 window.moji
│   └── renderer/                # 渲染进程（React，无 Node 权限）
│       ├── App.tsx              # 主界面
│       ├── components/          # ServiceCard / LogPanel / StatsCard …
│       ├── styles.css           # 暖琥珀设计系统（与博客一致）
│       └── types.ts             # 共享类型
├── tsconfig.main.json           # 主进程：NodeNext
├── tsconfig.preload.json        # preload：CommonJS
└── vite.config.ts               # 渲染进程：Vite + React
```

### 安全设计

渲染进程是一个**浏览器环境**，不接触系统能力：

- `contextIsolation: true` — 渲染进程与 preload 的 JS 上下文隔离
- `nodeIntegration: false` — 渲染进程里 `require` 不可用
- **白名单 IPC** — 所有能力走 `ipcMain.handle`，渲染进程只能调 preload 显式暴露的十几个方法
- **CSP 限制** — `index.html` 中限制只允许加载自身资源与 localhost 连接

### 几个实现细节

**进程独立存活**：启动服务时用 `spawn(..., { detached: true })` 配合 `child.unref()`，让子进程脱离 Electron 独立运行。这样关掉控制台（甚至退出应用），博客服务也不会被带走。

**优雅停止**：先发 `SIGTERM`，等 3 秒；仍在运行则 `SIGKILL`。之后还会用 `lsof -ti:<port>` 兜底清理——因为 `tsx` 和 `vite` 会派生孙进程，只杀父进程会留下孤儿。

**增量读日志**：不用每次都读整个文件。记下上次读到的字节偏移，之后从偏移处读新增内容（`readSince`）。文件被清空或轮转时自动回退为全量读取。

**端口探测**：`net.Socket` 尝试连接判断端口是否被占用，600ms 超时，避免卡住界面。

## 常见问题

**启动时提示「端口已被其他程序占用」**

说明 3000 或 5173 被别的程序占了（也可能是之前没用脚本直接 `pnpm dev` 启动的残留进程）。先释放端口：

```bash
lsof -ti:3000 | xargs kill      # 或
../scripts/start-local.sh stop all
```

**提示「依赖未安装」**

控制台只负责启动服务，不负责装依赖。按提示到对应目录执行 `pnpm install`。

**日志面板不刷新**

检查是否点了「暂停刷新」。另外日志文件位于 `logs/`，如果服务是用别的方式启动（没重定向输出到该文件），日志自然是空的。

**Electron 装不上 / 下载超时**

`.npmrc` 已配置国内镜像。海外网络如遇问题，删掉那两行镜像配置即可。
